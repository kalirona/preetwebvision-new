     1→     1→# Preet Web Vision — Project Worklog

     3→     3→## Project Overview
     4→     4→A stunning, modern digital marketing agency website for **Preet Web Vision** offering:
     5→     5→Website Design & Development, AI Automations, Web App Development, SEO & Digital Growth, Ecommerce Solutions.
     6→     6→
     7→     7→Single-route SPA (only `/` route visible). Multi-page experience handled via Zustand `useNav` store + `AnimatePresence` page transitions.

     9→     9→## Tech Stack
    10→    10→- Next.js 16 App Router, TypeScript, Tailwind CSS 4, shadcn/ui, Framer Motion, Lucide icons
    11→    11→- Prisma (SQLite) for contact submissions + chat leads
    12→    12→- z-ai-web-dev-sdk LLM for the live "Vision AI" assistant (`/api/chat`)
    13→    13→- Contact API at `/api/contact`

    15→    15→## Design System (IMPORTANT — follow these patterns)
    16→    16→- **Brand palette (warm, NOT indigo/blue):** orange `#FF6B35`, pink `#FF2D75`, rose `#F72585`, amber `#F59E0B`, emerald `#10B981`
    17→    17→- **Fonts:** `font-display` = Space Grotesk (headings), Geist Sans (body). Use `font-display` on headings.
    18→    18→- **Gradient helpers:** `.text-gradient-brand`, `.text-gradient-warm`, `.bg-brand-gradient`, `.bg-brand-gradient-soft`, `.animate-gradient-pan`
    19→    19→- **Glass:** `.glass`, `.glass-strong`; **glow:** `.glow-brand`, `.glow-soft`; **grid/dot bg:** `.grid-bg`, `.dot-bg`
    20→    20→- **Backgrounds:** `<AmbientBackground variant="strong|default|soft" />` from `@/components/site/ambient-background`
    21→    21→- **Marquee:** `.animate-marquee`, `.mask-fade-edges`
    22→    22→- **Float animations:** `.animate-float`, `.animate-float-slow`, `.animate-spin-slow`, `.animate-pulse-glow`, `.animate-shimmer`
    23→    23→- Dark mode is default (`defaultTheme="dark"`)
