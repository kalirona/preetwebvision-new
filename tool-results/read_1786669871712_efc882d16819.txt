     1→# Preet Web Vision — Project Worklog
     2→
     3→## Project Overview
     4→A stunning, modern digital marketing agency website for **Preet Web Vision** offering:
     5→Website Design & Development, AI Automations, Web App Development, SEO & Digital Growth, Ecommerce Solutions.
     6→
     7→Single-route SPA (only `/` route visible). Multi-page experience handled via Zustand `useNav` store + `AnimatePresence` page transitions.
     8→
     9→## Tech Stack
    10→- Next.js 16 App Router, TypeScript, Tailwind CSS 4, shadcn/ui, Framer Motion, Lucide icons
    11→- Prisma (SQLite) for contact submissions + chat leads
    12→- z-ai-web-dev-sdk LLM for the live "Vision AI" assistant (`/api/chat`)
    13→- Contact API at `/api/contact`
    14→
    15→## Design System (IMPORTANT — follow these patterns)
    16→- **Brand palette (warm, NOT indigo/blue):** orange `#FF6B35`, pink `#FF2D75`, rose `#F72585`, amber `#F59E0B`, emerald `#10B981`
    17→- **Fonts:** `font-display` = Space Grotesk (headings), Geist Sans (body). Use `font-display` on headings.
    18→- **Gradient helpers:** `.text-gradient-brand`, `.text-gradient-warm`, `.bg-brand-gradient`, `.bg-brand-gradient-soft`, `.animate-gradient-pan`
    19→- **Glass:** `.glass`, `.glass-strong`; **glow:** `.glow-brand`, `.glow-soft`; **grid/dot bg:** `.grid-bg`, `.dot-bg`
    20→- **Backgrounds:** `<AmbientBackground variant="strong|default|soft" />` from `@/components/site/ambient-background`
    21→- **Marquee:** `.animate-marquee`, `.mask-fade-edges`
    22→- **Float animations:** `.animate-float`, `.animate-float-slow`, `.animate-spin-slow`, `.animate-pulse-glow`, `.animate-shimmer`
    23→- Dark mode is default (`defaultTheme="dark"`)
    24→
    25→## Shared Primitives (`@/components/site/primitives`)
    26→- `<Reveal delay y className>` — scroll reveal
    27→- `<SectionHeading eyebrow title description align="center|left" className>`
    28→- `<GradientText>` — brand gradient text span
    29→- `<StaggerGroup>` + `staggerItem` variant — staggered grids
    30→- `<Counter value suffix duration>` — animated number counter
    31→- `<Marquee items reverse>`
    32→
    33→## Site Data (`@/lib/site-data.ts`)
    34→Exports: `NAV_ITEMS`, `SERVICES` (5, each with icon/title/tagline/description/features/deliverables/accent/glow), `PROJECTS` (6, with category/metric/gradient/emoji), `STATS`, `PROCESS` (4 steps), `TESTIMONIALS` (5), `TEAM` (4), `VALUES` (4), `TIMELINE` (4), `PRICING` (3), `FAQS` (6), `TECH_STACK`, `AWARDS`, `TRUSTED_BY`, `FEATURES_GRID`.
    35→
    36→## Navigation
    37→`useNav()` from `@/lib/nav-store` → `{ page, setPage }`. Call `setPage('home'|'services'|'portfolio'|'about'|'pricing'|'contact')` to navigate. Auto-scrolls to top.
    38→
    39→## Layout Structure
    40→`page.tsx` renders: `<Navbar />` + `<main className="pt-24">` (page transitions) + `<Footer />` (sticky via `mt-auto`) + `<AiAssistant />` (floating chatbot). Root wrapper is `min-h-screen flex flex-col`.
    41→
    42→## Existing Components
    43→- `@/components/site/navbar.tsx` — fixed glass navbar, mobile sheet, theme toggle, animated nav pill
    44→- `@/components/site/footer.tsx` — CTA strip + 5-col links + newsletter + socials + bottom bar
    45→- `@/components/site/ai-assistant.tsx` — floating LLM chatbot widget (talks to /api/chat)
    46→- `@/components/site/pages/home-page.tsx` — REFERENCE for design language (Hero, ServicesOverview, StatsBand, WhyUs, Process, PortfolioPreview, Testimonials, AiDemoCta, TechStack, FaqSection)
    47→
    48→## APIs
    49→- `POST /api/contact` — body `{name,email,company?,service?,budget?,message}` → `{ok, id}`
    50→- `POST /api/chat` — body `{messages:[{role,content}], email?}` → `{ok, reply}`
    51→
    52→## DB Models
    53→- `ContactSubmission`: id,name,email,company,service,budget,message,status,createdAt
    54→- `ChatLead`: id,email,message,createdAt
